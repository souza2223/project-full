# Kimkim Lanches — site institucional

Primeira versão visual para a pizzaria e hamburgueria **Kimkim Lanches**.

## Arquivos
- `index.html`: estrutura da página e conteúdo inicial.
- `style.css`: identidade visual, layout responsivo e estilos mobile.
- `script.js`: navegação mobile, filtros de cardápio e carrinho demonstrativo.

## Direção visual
- Estética editorial contemporânea, com tons de carvão, creme e laranja.
- Tipografia Playfair Display + DM Sans.
- Página inicial, destaques do cardápio, seção de marca, diferenciais e chamada final.
- Layout responsivo para celular, tablet e desktop.

## Importante nesta etapa
- As imagens são referências temporárias externas do Unsplash, não fotos oficiais da Kimkim.
- Produtos, preços, horários, área de entrega, telefone/WhatsApp e dados reais ainda não foram informados.
- O carrinho é apenas demonstrativo e não conclui pedidos nem pagamentos.
- O cardápio e a identidade serão ajustados quando o proprietário enviar as fotos e os dados oficiais.

## Como visualizar
O projeto é estático: basta servir a pasta por uma hospedagem de site estático. Em serviços como Vercel, selecione o repositório e publique a raiz; não é necessário configurar um framework para esta versão.
